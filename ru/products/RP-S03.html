Фильтры для душа

RP-S03 / RP-S04

Прямоугольный фильтр для душа (CL-SH5) — два варианта. RP-S03 возглавляет семейство.

RP-S03 и RP-S04 — два варианта одного фильтра для душа с общими базовыми значениями характеристик ниже. Они различаются формой насадки и картриджем: RP-S03 (прямоугольная насадка, корпус из ABS с окрашенной отделкой, варианты картриджей ACF / витамин C + ACF / средство против накипи + KDF + ACF); RP-S04 (кольцевая насадка, корпус PC + ABS с силиконовым уплотнительным кольцом, PP + картридж с ароматом витамина C). Спецификации подтверждаются для каждой модели и заказа.

О RP-S03

RP-S03 — фильтр для душа, очищающий воду до душевой лейки. Выпускается в двух формах насадок — прямоугольной и кольцевой — с одинаковыми основными характеристиками. Варианты картриджей: ACF, витамин C, средство против накипи и KDF, чтобы фильтр подходил к воде клиентов бренда. Сделан для владельцев брендов, которым нужен простой продукт для душа в линейку для ванной.

Почему покупатели выбирают его

  • Выбор картриджа: ACF, витамин C + ACF, средство против накипи + KDF + ACF или PP + картридж с ароматом витамина C на варианте с кольцевой насадкой.
  • Расход для душа 5–7 л/мин при рабочем давлении 0,1–0,4 МПа, для муниципальной водопроводной воды при 5–60°C.
  • Срок службы картриджа — около 3 месяцев, с понятным циклом замены.
  • Две формы насадок из одного семейства: прямоугольная (ABS, окрашенная отделка) или кольцевая (PC + ABS с силиконовым уплотнительным кольцом).

Лучше всего подходит для

  • Домохозяйства, которым нужна фильтрованная вода в душе.
  • Отели и арендные квартиры, оборудующие ванные комнаты.
  • Бренды, добавляющие фильтр для душа в линейку для ванной или водоочистки.

Часто задаваемые вопросы

Каков минимальный объём заказа?

Первый заказ — 200 единиц на модель, повторные заказы — 500 единиц.

Можно ли заказать образец до оптового заказа?

Да. Образцы готовы через 15 дней, стоимость образца возвращается при первом оптовом заказе. Оптовые заказы занимают 40 дней после утверждения образца и отгружаются FOB Шэньчжэнь.

Как долго служит картридж?

Приблизительно 3 месяца.

Два варианта — указывать при заказе как RP-S03 и назвать вариант (прямоугольная или кольцевая насадка).
