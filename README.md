Full static website based on the supplied ropureoem-v4-preview.zip: 75 HTML pages and 62 product detail pages, with the approved petrol/cyan/coral identity.

## Preview

Open index.html directly after extracting the entire ZIP. All site links, CSS, JavaScript, images, and original final logos are included. No build or dependencies are required. The GitHub preview/v5/ directory contains the same full static site.
