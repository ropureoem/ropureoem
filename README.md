# ROPureOEM

Approved final identity sourced byte-for-byte from ROPureOEM_Final_Petrol_Cyan.zip.

- `public/brand/`: eight approved SVG + PNG originals (1600×480 logos and 1024×1024 icons; light/dark).
- `docs/brand/VI-COLOR-SYSTEM.md`: exact palette and usage rules.
- `docs/brand/colors.json`: machine-readable colors and contact email.
- `docs/brand/logo-manifest.json`: original SHA-256 hashes and dimensions.
- `styles/brand-tokens.css`: reusable website color tokens.
- `preview/v5/index.html`: responsive identity and UI color specimen, with info@ropureoem.com.
- `preview/v5/STATUS.md`: completed and blocked work.
- `releases/ROPureOEM-v5-brand-preview.zip`: portable brand preview package, not a completed website release.

Open `preview/v5/index.html` after extracting the complete package, preserving folders. The page uses supplied PNGs for exact typography across platforms. The SVGs remain unchanged and retain their original font stack. No package installation or server is required.
